# Retro

Review task notes, local telemetry counts, verification history, and judge outcomes without copying source or
prompt content. Separate facts from interpretation: what happened, what cost time, what control helped, and
what should change next.

Capture one small follow-up in the backlog or task notes. Do not weaken a guard merely because it blocked an
unclear request; improve the scope, error message, or onboarding path instead.
