# CEO Review

Run the product part of Plan. Review the brief and choose one mode: Expansion, Selective Expansion, Hold
Scope, or Reduction. State the target user, promised outcome, non-goals, adoption trigger, and the smallest
release that can prove value.

Write the decision into the task Goal, Scope, and Pass/Fail Criteria. Do not implement. The task file remains
the durable handoff to `plan-eng-review`.
