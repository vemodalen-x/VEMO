VEMO 安装与维护

setup 是可选的事务式安装插件。它从独立 VEMO 源码 checkout 向一个已有 Git 仓库安装最小核心，并在写入后运行本地探针。

要求

  • Python 3.10+
  • Git，目标目录已 git init
  • Bash 4+ 用于 Git hooks
  • 目标仓库使用独立 .git，没有自定义 core.hooksPath

无图形安装

python3 plugins/setup/entry.py setup install /absolute/project --preset python --profile solo --json
python3 plugins/setup/entry.py setup install /absolute/project --preset python --profile solo --apply --plan-id '<plan-id>' --json
python3 plugins/setup/entry.py setup check /absolute/project --json

第一条只预览。检查文件清单和冲突后，把返回的内容绑定 plan_id 传给 --apply；缺少或不匹配时安装器拒绝写入。目标仓库中的旧 vemo.config.yaml 会使预览 fail-closed，必须先显式映射 critical paths 和 verification。

图形向导

从源码根目录运行：

python3 plugins/setup/entry.py ui
# 或运行 plugins/setup/ui/start.command

Windows 使用 py -3 plugins/setup/entry.py ui 或启动脚本。服务仅监听回环地址，无账号或云服务。

安装内容

默认核心 payload 是 14 个文件：policy、task 模板、CLI、evaluator、hooks、Git/CI adapters、tests 和 eval runner。不安装 Fleet、UI、product、skills 或其他插件到目标项目。

升级、恢复、卸载

python3 plugins/setup/entry.py setup recover /absolute/project --apply
python3 plugins/setup/entry.py setup uninstall /absolute/project --json
python3 plugins/setup/entry.py setup uninstall /absolute/project --apply --plan-id '<plan-id>'

安装清单位于目标的 .vemo/install.json。验证失败会自动回滚；卸载遇到安装后修改会停止，不删除用户后续变更。

边界

安装器不能配置远端分支保护、安装 Python、提供 OS 沙箱或替你完成业务测试。请在代码托管平台要求 vemo CI check，并用 CODEOWNERS 保护 policy、task、enforcement 和 workflow 文件。
